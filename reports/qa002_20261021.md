## Закрытые пробелы

- Существующий gate теперь требует 12 конкретных LLM acceptance test IDs:
  успешное grounded извлечение, failure/fallback, budget/circuit breaker,
  безопасную диагностику, cache revalidation, text-only request, реальный
  loopback transport, deadline, physical-attempt ledger и malformed/cache paths.
  Новый regression сначала воспроизвёл ложный PASS suite без этих проверок.
- Property suite обнаружила [#158](https://github.com/CRUDoshleps/GoodsAI/issues/158):
  старый stdlib HTMLParser падал на `<![x]>`. Узкое восстановление marked
  declaration сохраняет raw offsets и hidden-node state. Отдельная регрессия
  поймала и исправила сдвиг координат до stdlib AssertionError. Постоянные
  проверки есть для CLI batch, API, видимых фактов рядом и propagation interrupts.
- Первая попытка property suite не имела declared extra `fuzz`. Зависимость
  установлена из проекта, неуспешный preflight сохранён. Генератор и проверки
  не удалялись; исходный seed повторён успешно.
