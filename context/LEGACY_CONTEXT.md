## Решения по объёму

- На чекпоинт: одна категория, 3–5 характеристик, несколько понятных примеров и сценарий проверки результата. Размер демо — рекомендация команды, не условие организаторов.
- Достаточен связный концептуальный показ. Небольшое извлечение на правилах полезно при наличии времени; полноценная модель не заявлена обязательной на скриншоте.
- После чекпоинта: baseline и один эксперимент ML **или** LLM на одинаковой выборке. Полный каскад rules → encoder → LLM не обязателен по PDF, стр. 16–18.
- Полный анализ 31 млн строк поисковых событий, обучение encoder, интерфейс продавца, traffic queue, автоматическое дообучение и production-инфраструктура отложены.
- Нельзя выдавать макетные confidence, параметры каталога или чужие метрики за измеренное качество GoodsAI.

В этом обновлении меняются только материалы `context/`. Исправления исходных ТЗ/библиографии перечислены как следующие действия; продуктовый код не реализовывался.
