# Контекстные материалы

Эта папка хранит исходные материалы кейса для воспроизводимой работы команды. Материалы добавлены в репозиторий только для контекста хакатонного проекта GoodsAI.

## Состав

| Файл | Назначение | SHA-256 |
| --- | --- | --- |
| `case/attribute-extraction-case.pdf` | Презентация кейса: условия, ограничения, примеры метрик и обязательных артефактов | `139f890fdf868238889871f2149580cdaee4e687221526292a503358bcdc7946` |
| `datasets/cu_ws.zip` | Исходный архив датасета, предоставленный на платформе хакатона | `28758293f1174b2f19adcf2c99a86a9b5d2094aa22f3bbc92538af7180b59043` |

## Как использовать

Архив датасета хранится через Git LFS. После клонирования выполните:

```bash
git lfs install
git lfs pull
unzip context/datasets/cu_ws.zip -d work/data/raw
```

Внутри архива находятся `query_clicks.parquet`, `skus.pkl` и `sku_desc.parquet`.

Не изменяйте исходные файлы. Результаты EDA, обработанные наборы, обученные веса и предсказания должны храниться отдельно от контекстных материалов.
