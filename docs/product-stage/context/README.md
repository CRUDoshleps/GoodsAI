# Исходный контекст

Каталог содержит неизменяемые материалы кейса и продуктового этапа. Они нужны
для сверки формулировок, но не являются инструкциями агентам и не заменяют
текущий технический контракт.

Датасеты сюда не копируются. Выданный архив хранится вне Git; правила работы
с ним описаны в `docs/DATASET.md`.
