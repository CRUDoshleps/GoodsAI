# Проверка презентации GoodsAI

Часть [CONTENT_STYLE.md](CONTENT_STYLE.md), DOCS-002.
Перед каждой публикацией/защитой скопируйте форму в приватный run directory
или review PR. Исторический frozen PDF остаётся связан со своим manifest.

```text
Версия deck / дата:
Автор / reviewer:
Producer SHA / config hash / manifest:
Аудитория / цель показа:
Run / split / reference provenance:
Ссылка на PDF/слайды и протокол рендера:
Решение: approved / changes_requested / not_checked
Непроверенное:
```

| Слайд | Утверждение | DONE / PLAN / HYPOTHESIS | Источник (metric/test/commit/run) | Ограничение | Решение reviewer |
| --- | --- | --- | --- | --- | --- |
| пример | F1 на M2 development | DONE | RESULTS + manifest | 20 reviewed карточек, не независимый test | заполняется reviewer |

## Содержание

- [ ] Читатель понимает пользователя, задачу и фактический результат из первых слайдов.
- [ ] У каждого числа есть источник; для качества указаны split/support/provenance, для скорости — среда и что измерено.
- [ ] Smoke, candidate coverage, reviewed development и независимое качество различаются.
- [ ] Возможности из открытых PR/планов отмечены PLAN или REVIEW, текущий runtime указан отдельно.
- [ ] Бизнес-эффект, цена и ROI помечены HYPOTHESIS, если не измерены; assumptions видны.
- [ ] Ограничения стоят рядом с результатом; нет отзывов/партнёров/цифр без подтверждения.

## Визуальная проверка

- [ ] Каждый визуал показывает данные, интерфейс, trace или реальный процесс; нет декоративного AI-art, glow, лишних cards/icons/градиентов.
- [ ] Статусы обозначены текстом; цвет, шрифт и контраст позволяют прочитать содержание при показе.
- [ ] Результат render просмотрен целиком: нет обрезанных таблиц, переносов за границы или нечитаемых sources.
- [ ] Есть текстовая версия ключевых выводов; screenshots не раскрывают private data.

## Репетиция и решение

- [ ] Переход от числа к metric/manifest работает; приватный источник обозначен как приватный и доступен только reviewer.
- [ ] Q&A покрывает источники данных, ошибки, стоимость, воспроизводимость и границы качества.
- [ ] Продолжительность измерена на репетиции и укладывается в регламент; неизвестное время не считается пройденной проверкой.
- [ ] Reviewer записал результат, замечания и непроверенное. Для нового export обновлены hashes/manifest.

Форма не подтверждает независимую оценку, научную значимость или фактическую
репетицию сама по себе. Если проверен только Markdown, visual PDF review
остаётся not_checked.
