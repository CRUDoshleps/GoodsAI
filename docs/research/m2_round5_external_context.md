## Что подтверждает внешний источник

По прямой ссылке пользователя открыта публичная страница производителя и
связанное руководство. Производитель различает базовый артикул и цветовой
вариант; руководство называет базовую модель без слэш-суффикса. Это полезное
свидетельство для разбора конкретной серии. Реальные строки датасета не
передавались в поиск/API. Детали и URL сохранены локально в round5.feedback.json,
внешний контекст не подставлен в extractor и не превращён в справочник ответов.

Утверждения о «почти универсальном» значении слэша и международном BL=Black
представленными источниками не обоснованы. Схема одного производителя не
задаёт схемы остальных. Для примера, [официальная страница Phoenix Contact](https://www.phoenixcontact.com/en-nl/products/feed-through-terminal-block-pt-10-twin-bk-1375410)
использует BK для чёрного и BU для синего. Это не словарь бытовых чайников,
а контрпример универсальности буквенного кода. Две альтернативные расшифровки
другого суффикса в ответе внешнего ИИ остаются непроверенными предположениями.

## Предложение для строгого reference

Если граница базовой модели/варианта выясняется только из внешней документации,
изолированный индекс в карточке не считать однозначным указанием этой границы.
Предложено model=ambiguous; прежний полный индекс не объявляется достоверным
каноническим ответом только потому, что он буквально написан в title.
Формальное evidence само по себе не гарантирует верную семантику model.

Проверенный человеком внешний цвет и подтверждённая производителем базовая
модель сохранены в отдельном external_context. Прямой color остаётся absent:
в разрешённой карточке нет слова цвета и согласованной расшифровки кода.
Не добавлять объём/мощность из открытого руководства.

Возможны два подхода:

- Строгий text-only reference: неизвестная роль суффикса ambiguous, внешняя
  корректировка отдельно. Это рекомендуемый вариант при текущей политике.
- Позже отдельно согласовать версионированный справочник производителя/семейства
  с проверяемым происхождением. Он может позволить нормализовать такие индексы,
  но потребует общего протокола и измерения; нельзя добавить один SKU как ответ.

Последнее предложение ждёт подтверждения пользователя. Никакого общего
правила «отрезать всё после слэша» не вводится. M3 не решает нехватку
текстового обоснования одним уверенным ответом LLM.
